# 대한민국 육군학생군사학교 문무대교회 웹 플랫폼

조국 수호의 최전선으로 나아갈 학군사관(ROTC) 및 학사장교 후보생, 국군 장병, 군인가족을 위한 **문무대교회 공식 웹 플랫폼**입니다.

---

## 🌟 핵심 구현 기능

1. **경건하고 은혜로운 교회 첫 화면 (UI/UX)**
   - 대성전과 십자가의 장엄한 히어로 섹션
   - 오늘의 말씀(전도서 12:1) 및 정기 예배 시간표(주일 1부, 주일 2부 후보생 예배, 수요 찬양, 금요 심야)
   - 최신 주일 설교 유튜브 비디오 플레이어 & 스마트 주보 뷰어
   - 부대 위치 및 위병소 보안 출입 안내

2. **교회 40년 연혁 & 사진 갤러리**
   - 1985년 학생중앙군사학교(성남) 창설기부터 2011년 충북 괴산 신축 대성전 헌당, 2026년 현재까지의 인터랙티브 타임라인
   - 1,200석 대예배실, 진중세례식, 찬양 연합예배, 십자가 동산 고화질 갤러리 (라이트박스 확대 지원)

3. **스마트 목양상담 접수 시스템**
   - 군종목사 상담 가능 일자/시간 슬롯 실시간 조회 및 예약
   - 예약 완료 시 **구글 캘린더 자동 등록 링크(Google Calendar Event URL)** 및 ics 파일 다운로드 지원
   - 군부대 특성을 고려한 **비밀보장 모드 (익명 닉네임 + 4자리 비밀코드)** 및 상태 조회

4. **외부 위문 신청 관리 시스템 (일정 중복 방지)**
   - 동일 일자/시간대 중복 신청 자동 차단
   - 위문 물품(햄버거, 텀블러 등), 방문 인원, 부대 위병소 출입 차량번호 사전 등록
   - 군종실 심의 및 승인/조율/반려 워크플로우

5. **정기 종교행사 및 진중세례 접수**
   - 하계/동계 ROTC 진중세례식, 찬양의 밤 행사 상세 안내
   - 정원 카운터 및 참여자 온라인 신청 접수

6. **군선교 후원 계좌 & 실시간 입금 알림**
   - 농협, 국민, 신한 공식 후원 계좌 원클릭 복사
   - 후원자가 입금 후 [입금 확인 알림 전송] 시 관리자 대시보드 실시간 반영 및 알림 연동

7. **3D 인터랙티브 가상 목양실 (Three.js 기반)**
   - 브라우저에서 360° 마우스 드래그로 회전하는 3D 목양실/채플 공간
   - 반짝이는 핫스팟 클릭: 십자가 축복기도, 성경 말씀 카드, 1:1 상담 연결, 잔잔한 피아노 찬양 BGM 재생

8. **군종행정 통합 관리자 대시보드 (Admin)**
   - 기본 계정: `admin` / `munmu1234!`
   - 상담 신청 접수/확정/코멘트 입력
   - 위문 일정 승인 및 위병소 통보 메모 관리
   - 후원금 입금 확인 완료 처리
   - 행사별 등록자 명단 조회

## 🚀 실행 방법

### 1. 가상환경 및 의존성 (이미 설치 완료됨)
```bash
py -3.11 -m pip install -r requirements.txt
```

### 2. 서버 실행
```bash
py -3.11 run.py
```
서버가 시작되면 웹 브라우저가 자동으로 열리며, 아래 주소로 직접 접속할 수도 있습니다:
* **메인 홈페이지**: http://localhost:8000
* **목양상담 센터**: http://localhost:8000/counseling
* **위문 신청 센터**: http://localhost:8000/consolation
* **행사 & 진중세례**: http://localhost:8000/events
* **3D 가상 목양실**: http://localhost:8000/virtual-space
* **교회 소개 & 연혁**: http://localhost:8000/about
* **후원 계좌 & 알림**: http://localhost:8000/donation
* **관리자 대시보드**: http://localhost:8000/admin (ID: `admin` / PW: `munmu1234!`)
